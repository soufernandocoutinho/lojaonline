# Loja Guia Panorama

Página de vendas do Guia Panorama para apresentar e solicitar soluções digitais, como cardápio digital, catálogo online, cartão de visitas digital, SmallBio e convite digital.

## Sobre

A loja oferece sites mobile personalizados com pagamento vitalício. O cliente também pode optar pela inclusão de uma assinatura anual de sistemas, conforme as opções e condições disponíveis para cada solução. Os pedidos podem ser configurados na página e encaminhados para atendimento pelo WhatsApp.

## Tecnologias

- HTML5 para a estrutura e o conteúdo da página.
- CSS3 para os estilos e a adaptação a diferentes tamanhos de tela.
- JavaScript para interações, configuração de produtos, carrinho e fluxo de pedidos.
- Bootstrap 5.3.3 para componentes e recursos de layout responsivo.
- Integração com serviços NextGo para catálogo e processamento de pedidos.
